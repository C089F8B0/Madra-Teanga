# Development Setup

## Prerequisites

This project is built with **ClojureDart**. You will need:

1.  **Clojure**: Follow the [official installation guide](https://clojure.org/guides/install_clojure).
2.  **Flutter**: Follow the [Flutter installation guide](https://docs.flutter.dev/get-started/install).
3.  **ClojureDart**: Follow the [ClojureDart setup guide](https://github.com/Tensegritics/ClojureDart/blob/main/doc/docs/01-getting-started.md).

## Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Madra-Teanga/Madra-Teanga.git
    cd Madra-Teanga
    ```

2.  **Install dependencies**:
    ```bash
    flutter pub get
    ```

3.  **Run the application**:
    ```bash
    clj -M:cljd flutter run
    ```
