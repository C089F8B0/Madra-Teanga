# Madra Teanga (Réamh-Fhorbairt)

> [!IMPORTANT]
> **Leagan Gaeilge**: Tá an leagan seo den tionscadal curtha in oiriúint don Ghaeilge.
> **English Reference**: For the English version of this project, please check the [Béarla branch](https://github.com/l-Shane-l/Madra-Teanga/tree/B%C3%A9arla).

Is é **Madra Teanga** an comharba foinse oscailte ar [sionnach.app](https://sionnach.app).
Tabhair cuairt ar an suíomh oifigiúil: [madrateanga.com](https://madrateanga.com/)

## Ailtireacht

Úsáideann an tionscadal seo **Draíocht**, DSL nua bunaithe ar Clojure-Dart le haghaidh Flutter, a ligeann duit aipeanna soghluaiste a chruthú trí mheán na Gaeilge.

## Tús a Chur Leis

Féach ar an [Doiciméadúchán](doiciméadúchán/socrú.md) le haghaidh treoracha mionsonraithe socraithe (Béarla faoi láthair).

### Tús Mear
1.  Suiteáil [Clojure](https://clojure.org/guides/install_clojure) agus [Flutter](https://docs.flutter.dev/get-started/install).
2.  `flutter pub get`
3.  `clj -M:cljd flutter run`

## Cruthú Ceachtanna

Tá an cód foinseach do **Madra Teanga**, feidhmchlár foghlama Gaeilge foinse oscailte, sa stór seo.
Léiríonn sé úsáid **Draíocht** chun aipeanna tras-ardáin a thógáil i nGaeilge.

Is féidir leat na ceachtanna a athrú trí `assets/deck.json` a chur in eagar agus comhaid fuaime a chur leis.
Féach ar an [Treoir Chruthaithe Ceachtanna](doiciméadúchán/cruthú_ceachtanna.md) le haghaidh sonraí.
